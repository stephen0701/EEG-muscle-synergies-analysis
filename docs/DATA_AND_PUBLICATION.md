# Data and publication

Both research repositories were private when inspected. Portfolio preparation preserves that visibility and adds no participant recordings, metadata tables, or new data downloads to GitHub.

The owner authorized all eight supplied Chapter 5 figures for inclusion in this private portfolio repository, including originals accompanied by explicit label corrections and analysis caveats. Figure files are in `docs/figures/`; their original bytes are preserved. The complete supplied brief remains local. No raw recordings or participant identifiers were supplied as example data.

Private inputs should stay outside the checkout. `.gitignore` covers common recording formats, metadata spreadsheets, pickles, NumPy arrays, motion files, videos, local settings, and generated result directories. Ignore rules do not remove already-tracked material or erase Git history.

The owner identified the existing *Digital Signal Processing of Cortical and Muscular Dynamics* PDF as this project's report. It is now organized under [docs/reports/](reports/README.md), with the original Git blob reused so its contents are unchanged. The file has not received a content/privacy review because binary retrieval did not yield inspectable contents. The report link does not imply independent verification of its findings or public-release permission. No history was rewritten.

Before any future visibility change, verify the complete history, PDF contents, figure metadata, contributor rights, and participant-release permissions. Public release was not requested or performed. Missing data/code rights must not be inferred from repository access.
